# TDrive v2.2.0

Draft notes for the next stable release.

## New

- Browse connected supergroups by topic, including General and All topics.
  Search files within a topic and choose topics through a desktop popover or
  mobile bottom sheet. [#150](https://github.com/jeetrex17/TDrive/pull/150)
- View images, PDFs and text/code files from connected sources alongside video
  and audio. Protected media supports viewing and streaming with in-app saving,
  copying and forwarding disabled. [#145](https://github.com/jeetrex17/TDrive/pull/145)
- Add Windows MSIX packaging for Microsoft Store submission and Store-managed
  updates for packaged Windows installs. Store availability depends on Microsoft's
  certification process. [#146](https://github.com/jeetrex17/TDrive/pull/146)

## Fixes

- Open previews and streams for shared-drive Telegram attachments, including
  forwarded files, ordinary posts and Telegram photos. Refresh stale access
  hashes when needed. [#143](https://github.com/jeetrex17/TDrive/pull/143)
- Wait through Telegram upload cooldowns until canceled while retaining uploaded
  bytes and send identities. Wait for backend readiness before restoring the
  session and saved drive. [#149](https://github.com/jeetrex17/TDrive/pull/149)
- Keep playback-speed controls responsive during WebKit playback updates.
  [#143](https://github.com/jeetrex17/TDrive/pull/143)
