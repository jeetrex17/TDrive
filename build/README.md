# Build Directory

Houses the build assets consumed by the Taskfile-based Wails v3 build
(`../Taskfile.yml` + `Taskfile.yml` + `darwin/`, `linux/`, `windows/` here).

Common commands (run from the repo root):

- `wails3 dev` - development mode with hot reload
- `wails3 task build` - build the binary for the host OS into `build/bin`
- `wails3 task package` - build + package (macOS `.app`, Windows NSIS installer,
  Linux AppImage) into `build/bin`
- `wails3 task -l` - list all available tasks

Product metadata (name, identifier, version, company, copyright) lives in
`config.yml`. After editing it, run `wails3 task common:update:build-assets`
to regenerate `darwin/Info.plist`, `darwin/Info.dev.plist`,
`windows/info.json` and `windows/wails.exe.manifest` - this OVERWRITES those
files, so re-apply any hand edits afterwards (currently: the
`NSAppTransportSecurity`/`NSAllowsLocalNetworking` block in both darwin
plists). `windows/installer/wails_tools.nsh` is also regenerated by that
command, written by hand into this repo to match; `windows/installer/
project.nsi` is not touched by it and is meant to be hand-edited.
`linux/TDrive.desktop` is maintained entirely by hand (custom Comment and
Categories) and is never regenerated automatically - see
`linux:generate:dotdesktop` in `linux/Taskfile.yml` if you want to start over.

## macOS

- `appicon.png` - source icon; `darwin/icons.icns` is generated from it via
  `wails3 task common:generate:icons` (also runs automatically before every
  darwin build).
- `darwin/Info.plist` - used for `wails3 task build`/`package`.
- `darwin/Info.dev.plist` - used for `wails3 task darwin:run` (dev-mode app
  bundle).

## Windows

- `windows/icon.ico` - hand-provided; NOT regenerated by `generate:icons`.
- `windows/info.json` - version/resource info embedded into the `.exe`.
- `windows/wails.exe.manifest` - the application manifest.
- `windows/installer/` - NSIS installer scripts (`project.nsi` +
  `wails_tools.nsh`), used by `wails3 task windows:package`.

## Linux

- `linux/TDrive.desktop` - the `.desktop` entry, packaged into the AppImage.
- `linux/appimage/` - working directory for `wails3 task linux:package`
  (AppImage build); the produced `.AppImage` goes to `build/bin`.
